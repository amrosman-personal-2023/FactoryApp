# FactoryApp

This repository contains a small factory/order-management sample app with a legacy implementation kept under the `Legacy/` directory.

The legacy application is a Python-based terminal UI built with `curses` and backed by a SQLite database. It includes customer lookup, order entry, order tracking, and sales reporting workflows, with the business logic and screen flow defined in `Legacy/ordersys.py` and the database schema/seed data in `Legacy/db.py`.

It represents the original green-screen system that is being preserved for migration or modernization work.
